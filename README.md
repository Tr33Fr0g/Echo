# ECHO
A local AI butler that lives inside and around my PC. 

## What does it do right now:
- Answers questions without using internet
- Gives personalized responses with a set humour
- Greets the user and remembers past chats

## How to run it:
1. Install Ollama from https://ollama.com/download
2. Download the model in terminal using "ollama pull qwen3.5:9b"
3. Install the Python Library in terminal "python -m pip install ollama"
4. Download this repo and open its folder in a terminal
5. Start Echo: "python echo.py"

## Commands:
- /help | Shows the entire list of commands
- /reset | Makes Echo forget history but keep personality
- /history | Shows how many messages are in the conversation
- /quit | Saves the conversation and closes Echo
